# 仪表盘页面实现说明

## 功能概述
已实现智慧能源管理系统仪表盘（Overview）页面，包含以下功能模块：

### 1. KPI 卡片区（3 个）
- **今日总能耗**：显示实时能耗数据（MWh），带同比昨日增减百分比
- **在线设备率**：显示设备在线百分比，标注异常设备数量
- **今日 CO₂减排**：显示根据能耗换算的二氧化碳减排量（kg）

### 2. 图表区
- **各建筑能耗占比环形图**：展示不同建筑的能耗分布，支持鼠标悬停查看详情
- **近 7 日总能耗趋势折线图**：展示能耗变化趋势，平滑曲线带面积填充

### 3. 异常列表区
- 显示最新 5 条异常/报警信息
- 包含：异常时间、建筑名称、异常类型、状态
- 支持行选择和查看详情跳转
- 点击任意项自动跳转到"数据查询与分析"页面并带入查询条件

## 技术实现

### 依赖库
- **Naive UI**：UI 组件库（卡片、表格、按钮等）
- **ECharts**：图表库（环形图、折线图）
- **@vicons/ionicons5**：图标库（Ionicons 5 图标集）
- **Vue 3 + TypeScript**：响应式框架和类型系统

### 文件结构
```
client/src/
├── views/
│   └── Overview.vue          # 仪表盘主页面
├── api/
│   └── dashboard.ts          # 仪表盘 API 接口（含 Mock 数据）
└── types/
    └── dashboard.ts          # 仪表盘相关类型定义
```

### Mock 数据
当前使用 Mock 数据进行演示，数据位于 `api/dashboard.ts` 中：
- KPI 数据：总能耗 1256.8 MWh，在线率 98%，CO₂减排 856.4 kg
- 图表数据：5 个建筑能耗占比，7 日能耗趋势
- 异常列表：5 条模拟异常记录

### 核心功能
1. **并行数据加载**：同时调用三个接口获取 KPI、图表、异常数据
2. **骨架屏占位**：加载过程中显示骨架屏
3. **图表自适应**：窗口大小变化时自动调整图表尺寸
4. **数据刷新**：点击右上角刷新按钮重新加载数据
5. **交互跳转**：点击异常项跳转到分析页面并带入查询条件

## 后续工作

### 1. 安装 ECharts 依赖
需要运行以下命令安装 ECharts：
```bash
cd client
npm install echarts --save
```

### 2. 后端接口对接
当后端 API 就绪后，在 `api/dashboard.ts` 中：
- 取消真实 HTTP 请求的注释
- 移除 Mock 数据部分

### 3. 路由配置
已在 `router/index.ts` 中配置路由：
```typescript
{
  path: '/Overview',
  name: 'Overview',
  component: () => import('@/views/Overview.vue'),
  meta: { requiresAuth: true }
}
```

### 4. 分析页面开发
需要创建 `/analysis` 路由对应的页面组件，用于：
- 接收异常详情传递的参数
- 展示详细的能耗分析数据
- 提供数据查询和分析功能

## 注意事项

1. **图标库**：使用 `@vicons/ionicons5` 作为图标解决方案，已随 ECharts 一起安装
2. **类型安全**：所有数据和接口都有完整的 TypeScript 类型定义
3. **响应式设计**：页面适配不同屏幕尺寸，图表自动调整
4. **数据安全**：使用了可选链操作符和条件渲染防止空值错误

## 启动说明

1. 确保已安装所有依赖：
   ```bash
   cd client
   npm install
   ```

2. 启动开发服务器：
   ```bash
   npm run dev
   ```

3. 访问 `http://localhost:8080/Overview` 查看仪表盘页面
