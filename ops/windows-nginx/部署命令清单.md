# TalkAlways Windows 部署命令清单

适用目录：

```text
C:\Users\Administrator\TalkAlways
```

适用分支：

```text
deploy/nginx-main
```

## 1. 拉取代码

```powershell
cd C:\Users\Administrator\TalkAlways
git fetch origin
git checkout deploy/nginx-main
git pull
```

如果本地还没有这个分支：

```powershell
cd C:\Users\Administrator\TalkAlways
git fetch origin
git checkout -b deploy/nginx-main origin/deploy/nginx-main
```

## 2. 启动后端

默认用系统里的 `python`，并自动安装后端依赖：

```powershell
cd C:\Users\Administrator\TalkAlways\ops\windows-nginx
.\start-backend.ps1 -RepoRoot C:\Users\Administrator\TalkAlways
```

如果系统里不是 `python` 这个命令名，改成显式路径：

```powershell
cd C:\Users\Administrator\TalkAlways\ops\windows-nginx
.\start-backend.ps1 `
  -RepoRoot C:\Users\Administrator\TalkAlways `
  -PythonExe C:\Python311\python.exe
```

如果不想重复安装依赖：

```powershell
cd C:\Users\Administrator\TalkAlways\ops\windows-nginx
.\start-backend.ps1 `
  -RepoRoot C:\Users\Administrator\TalkAlways `
  -SkipBackendDepsInstall
```

## 3. 部署前端并安装项目内 Nginx

首次部署建议直接用这条：

```powershell
cd C:\Users\Administrator\TalkAlways\ops\windows-nginx
.\deploy.ps1 `
  -RepoRoot C:\Users\Administrator\TalkAlways `
  -InstallFrontendDeps `
  -StartNginxIfStopped
```

这条命令会自动完成：

- 如果系统里没有 `npm`，下载 Node.js 到 `C:\Users\Administrator\TalkAlways\tools\nodejs`
- 如果项目里没有 `nginx`，下载到 `C:\Users\Administrator\TalkAlways\server\nginx`
- 执行前端构建
- 生成并写入 `nginx.conf`
- 启动或重载项目内 Nginx

如果前端依赖已经装过，后续更新可以用这条：

```powershell
cd C:\Users\Administrator\TalkAlways\ops\windows-nginx
.\deploy.ps1 `
  -RepoRoot C:\Users\Administrator\TalkAlways `
  -StartNginxIfStopped
```

## 4. 验收

检查后端健康：

```powershell
Invoke-WebRequest http://127.0.0.1:3000/api/health
```

检查前端首页：

```powershell
Invoke-WebRequest http://127.0.0.1
```

浏览器访问：

```text
http://服务器IP
```

## 5. 停止后端

```powershell
cd C:\Users\Administrator\TalkAlways\ops\windows-nginx
.\stop-backend.ps1 -RepoRoot C:\Users\Administrator\TalkAlways
```
